One word describing the boss. The whole entry is a single word — no
phrase, no caption, no explanation. It has to land on its own.

## The word

**Hoverer** — the boss who is always leaning over your shoulder.

Picked by pairwise judging with two independent judges (Caffeine router
and Verboo deepseek-v4.1-flash) over 8 candidates — Bosszilla, Hoverer,
Creditgrabber, Micromanager, Meetingmonster, Tasknado, Unreachable,
Overlord. Both judges picked Hoverer: a word a person would genuinely
use about their boss, funny on its own, true of a real boss habit,
fresher than "Micromanager", and it travels from kitchen to warehouse
to office — you can mime it at lunch.

## How it works

`main.py` deterministically writes exactly one word to
`/output/entry.txt`. No network calls, no randomness, no secrets.
It self-checks the bounty gate before writing: 1–30 characters,
exactly one word, not only whitespace.

Run it:

```sh
python3 main.py
```

Then `/output/entry.txt` contains `Hoverer` (7 characters, no trailing
newline). The output is deterministic — running it twice produces
byte-identical output (sha256
`9c3899648b50918dc9a2ad27c53dc035e39d06a7e958c3799a05082dd7bd0dac`).
